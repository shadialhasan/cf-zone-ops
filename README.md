# ☁️ cf-zone-ops

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Cloudflare: API v4](https://img.shields.io/badge/Cloudflare-API%20v4-orange.svg)](https://cloudflare.com)

High-productivity CLI utility tailored for infrastructure administrators managing fleets of hundreds of domains. Execute bulk cache invalidation, instant DDoS "Under Attack" shielding, and batch DNS synchronizations across entire zone portfolios.

## 🚀 Usage
```bash
export CF_API_TOKEN="your_token_here"
node index.js purge zoneId1,zoneId2,zoneId3
node index.js attack-mode zoneId1,zoneId2
```
